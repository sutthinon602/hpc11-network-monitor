📋 ประวัติบันทึกการขาดการติดต่อ (Downtime Incidents)

บันทึกวัน-เวลาที่สวิตช์ดับ และระยะเวลาจนกว่าจะกู้คืนสำเร็จอัตโนมัติ

ลำดับ เวลาที่เริ่มดับ (Downtime) ชื่ออุปกรณ์ (Device Name) IP Address จุดติดตั้ง / แผนก เวลากลับมาออนไลน์ (Recovered) ระยะเวลาที่ดับ สถานะ

⚙️ จัดการรายชื่ออุปกรณ์ที่ติดตาม (Admin Management)

เพิ่ม แก้ไข หรือลบสวิตช์ในระบบ และสร้างคำสั่งสำหรับนำไปใส่ใน MikroTik

ลำดับ ชื่ออุปกรณ์ IP Address กลุ่ม / แผนก รุ่นอุปกรณ์ สายลิงก์ต้นทาง จัดการ
